# Traffic Accident Data Analysis

## Overview
This project analyzes traffic accident data to identify patterns related to weather conditions, time of day, and accident severity. Data visualization techniques were used to understand accident hotspots and contributing factors.

## Objectives
- Analyze accident patterns
- Study weather and time-related factors
- Visualize accident hotspots
- Perform Exploratory Data Analysis (EDA)

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Kaggle US Accidents Dataset

## Features
- Weather Condition Analysis
- Time of Day Analysis
- Accident Severity Visualization
- Accident Hotspot Detection

## Output
The project generates visualizations such as:
- Bar Charts
- Histograms
- Scatter Plots
